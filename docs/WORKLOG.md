- 사용자 노출 문구는 한글을 기본으로 한다. 포켓몬 이름·타입·전투 로그·HUD·카드·결과 화면 모두에 적용한다.
- 고정 글자 크기는 11px 미만으로 내리지 않는다. 공간이 부족하면 여백·행 높이·패널 크기를 조정한다.

## 전장 HUD

- 중앙 표시 순서: `N 층` → `라운드` → 두 자리 라운드 수 → 현재 단계 → 점수.
- 층 표기는 `층 01`이 아니라 `1 층` 형식이다.

## 포켓몬 표기와 대표 기술

- 1~3세대 전투 캐릭터는 한글 이름과 한글 타입으로 표시한다.
- 선택 카드의 대표 기술은 `signatureSkill`로 관리한다. 현재 값:
  - 이상해씨: 씨폭탄 / 파이리: 화염방사 / 꼬부기: 아쿠아테일
  - 치코리타: 꽃잎댄스 / 브케인: 화염바퀴 / 리아코: 아쿠아테일
  - 나무지기: 리프블레이드 / 아차모: 블레이즈킥 / 물짱이: 머드봄
- 새 캐릭터는 그 캐릭터만 쓰는 공격 카드가 있으면 이를 대표 기술로 지정하고, 없으면 보유 공격 중 하나를 대표 기술로 지정한다.

## 스프라이트 앵커

- 전투 토큰의 실제 발끝(불투명 픽셀의 최하단)을 각 칸 중심에 맞춘다. 이미지 캔버스의 투명 여백을 기준으로 배치하지 않는다.
- 앵커 보정은 `backgrounds.css`의 `[data-pokemon] .token-art { bottom: ... }`에서 관리한다.
- 3세대 기본형 / 진화형 보정값(데스크톱):
  - 나무지기 -48%, 아차모 -50%, 물짱이 -52%
  - 나무킹 -25%, 번치코 -19%, 대짱이 -36%
- 모바일에서는 축소 비율에 맞춘 별도 보정값을 유지한다.

## 최근 반영

- 층 표시를 라운드 위의 `1 층` 형식으로 변경했다.
- 3세대 기본형과 진화형 모두 발끝 앵커 보정을 추가했다.
- 결과 화면은 승리·패배 모두 `전투 종료` 라벨과 큰 승패 제목이 겹치지 않도록 라벨 아래 32px 여백과 제목 1.0 줄높이를 유지한다.
- 패배 결과의 버튼은 `다시 시작`이며, 누르면 보상·최대치 강화·층·점수·연승을 초기화하고 캐릭터 선택 화면으로 돌아간다. 승리 결과의 `다음 전투` 흐름은 유지한다.
- 보상 `최대 체력 +10`과 `최대 의욕 +10`은 손패에 넣지 않고, 선택 즉시 영구 최대치와 현재치를 각각 +10 적용한다. 전장 하단의 `층 보상`에는 층별 선택 이력을 표시한다.
- 공격 카드 밸런스: 기본 기술은 고속 근접(우선순위 5)·표준(4)·강력 기술(3)으로 역할을 구분한다. 근접 기술은 28~35 피해/20~24 의욕, 표준은 22~30 피해/18~25 의욕, 강력 기술은 38~42 피해/30~33 의욕을 기준으로 한다. 사거리 3 기술은 피해 또는 우선순위에서 대가를 지불한다. 진화 기술과 보상 기술은 이 기준보다 한 단계 높은 성능을 유지한다.
- 승리 보상 공격 카드는 피해·의욕·사거리·우선순위를 모두 표시한다.
- 카드 미니 범위와 실제 전장 미리보기는 `cardRangePattern()`의 같은 3×3 인덱스 데이터를 사용한다. 이동 카드는 대각선·2칸 이동도 방향을 표시하며, 공격 기술은 전방·후방·상하·대각선·자기 칸을 포함한 광역 패턴을 캐릭터별로 사용한다. CPU는 좌우를 반전해 같은 패턴을 적용한다.
- 캐릭터 선택은 1세대부터 세로 섹션으로 정렬하고, 각 세대 안에서는 폭을 줄인 2열 카드 패널로 표시한다. 4세대는 모부기·불꽃숭이·팽도리와 각 진화체(토대부기·초염몽·엠페르트)를 같은 선택·진화 구조로 추가한다.
- 4세대 기본/진화 스프라이트도 실투명 여백을 측정해 발 위치 기준 앵커 보정을 `backgrounds.css`에 기록한다. 4세대 공격은 카드별 `pattern` 데이터를 우선 사용해 미니 범위와 실제 행동 범위가 일치한다.
- 선택 화면의 최종 배열은 4열×3행이다. 열은 1·2·3·4세대 순서이고, 각 열은 풀·불꽃·물 스타팅을 위에서 아래로 쌓는다. 개별 카드의 좌우 패딩과 아트 폭을 줄여 넓은 선택 패널을 피한다.
- 글로벌 랭킹은 Firebase `pokemonGTournamentRankings` 컬렉션을 사용한다. 패배 결과에서 Google 로그인과 닉네임(2~16자) 입력 후 저장하며, 닉네임·파트너·진행 층·총점수를 타이틀 오른쪽과 패배창에 함께 표시한다. 계정별 최고 점수(동점이면 더 높은 층)만 유지한다.
- Firebase Firestore 규칙은 게임 폴더의 `firestore.rules`를 콘솔에 배포해야 한다. 배포와 Google 로그인 도메인 설정 절차는 `FIREBASE_SETUP.md`에 기록한다.
- 랭킹 연결 프로젝트를 Firebase `PokemonGT`(`pokemongt-224d2`)로 교체했다. 이 프로젝트에 게임 전용 웹 앱 `포켓몬 G 토너먼트`를 등록했다.
