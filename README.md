# Pokémon // Grid Battle

로컬에서 실행하는 5×6 그리드 기반 카드 배틀 프로토타입입니다.

## 실행

프로젝트 루트를 정적 파일 서버로 열면 됩니다. 예를 들어 VS Code Live Server를 사용하거나, 프로젝트 루트에서 아래처럼 실행할 수 있습니다.

```powershell
python -m http.server 5500
```

그 다음 `http://localhost:5500/`를 엽니다.

## 이미지

선택 화면, HUD, 전투 토큰에는 PokeAPI sprites 저장소의 `official-artwork` PNG를 로컬 자산으로 내려받아 사용합니다.

## 규칙

- 1세대·2세대 스타팅 포켓몬 중 하나를 선택합니다.
- HP/EN은 100으로 시작합니다.
- 라운드마다 행동 카드 3장을 순서대로 선택합니다.
- 카드 우선순위 → 에너지 → HP → 이전 선행 순서로 행동 순서를 정합니다.
- 2라운드부터 1~3개의 불타는 타일이 추가되고, 해당 타일에서 턴을 시작하면 HP 20을 잃습니다.
