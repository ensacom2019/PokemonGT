# 포켓몬 G 토너먼트

5×6 전장에서 카드 3장을 순서대로 조합해 싸우는 턴제 포켓몬 배틀 게임입니다. 1~4세대 스타팅 포켓몬 중 파트너를 골라, 층마다 강해지는 상대를 꺾고 더 높은 점수에 도전하세요.

## 플레이

- 웹 게임: https://ensacom2019.github.io/PokemonGT/
- 로컬 실행: 프로젝트 폴더에서 `python -m http.server 5500`을 실행한 뒤 `http://localhost:5500/`으로 접속합니다.

## 게임 목표

상대의 체력을 먼저 0으로 만들면 전투에서 승리합니다. 승리 후에는 체력과 의욕을 일부 회복하고, 제시된 보상 3개 중 하나를 골라 다음 층으로 진행합니다. 연속 승리, 빠른 전투, 남은 체력, 피해량과 진화는 점수에 반영됩니다.

## 전투 진행

1. 파트너 포켓몬을 선택하고 전투를 시작합니다.
2. 매 라운드 손패에서 카드 3장을 골라 행동 순서를 정합니다.
3. `진행`을 누르면 양쪽의 카드가 1번부터 3번까지 차례로 실행됩니다.
4. 같은 순서의 행동은 카드 우선순위, 의욕, 체력, 직전 행동 순서로 선공을 결정합니다.
5. 라운드가 끝날 때마다 의욕을 5 회복하고, 불타는 위험 칸이 1~3개 추가됩니다.

## 카드와 전장

- 기본 카드: 상·하·좌·우 이동, 방어, 의욕 충전, 포켓몬별 고유 공격 3종
- 방어: 다음에 받는 피해를 50% 줄입니다.
- 의욕 충전: 의욕을 30 회복합니다. 같은 라운드에 충전 카드를 먼저 배치하면, 회복 후 의욕을 기준으로 다음 공격 카드를 사용할 수 있습니다.
- 위험 칸: 불타는 칸에서 행동을 시작하면 체력이 20 감소합니다.
- 기술 범위: 카드의 3×3 미니 범위와 전장 표시로 이동·공격 가능한 위치를 확인할 수 있습니다.

## 성장 요소

- 상성: 풀 → 물 → 불 → 풀 상성 공격은 피해가 1.5배가 됩니다.
- 진화: 피해를 주거나 받고, 라운드가 지날수록 진화 게이지가 찹니다. 진화 카드를 사용하면 공격 카드가 강화되고 진화 전용 기술과 뒤로 2칸 이동 카드가 추가됩니다.
- 승리 보상: 신규 공격·이동 카드, 카드 강화, 최대 체력·의욕 강화 중 하나를 선택합니다. 2칸 이동 카드는 의욕 6을 소모합니다.
- 전투 이벤트: 3층마다 전투 대신 이벤트가 발생합니다. 이벤트를 넘길수록 이후 적은 추가 보상을 가진 상태로 등장합니다.

## 랭킹

패배 후 Google 로그인과 닉네임을 입력하면 선택한 파트너, 진행한 최고 층, 총점이 랭킹에 기록됩니다.
